# Reference images

Images to follow when building the game. Every agent should look at these before building UI or art.

| Folder | What goes in it |
|--------|-----------------|
| `original-game/` | Screenshots of the Steam game, showing mechanics and layout to learn from (not to copy directly) |
| `ui/` | UI mockups and style references to match |
| `walls-and-art/` | Wall designs, tools, effects, map look |

Name files `short-description.png`, for example `shop-panel-mockup.png`. If an image needs explaining, add a line about it below.
