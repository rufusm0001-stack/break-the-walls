# Reference images

Images to follow when building the game. Every agent should look at these before building UI or art.

| Folder | What goes in it |
|--------|-----------------|
| `original-game/` | Frames from *Escape the Walls* (the Steam original), showing mechanics and layout to learn from (not to copy directly) |
| `roblox-competitor/` | Frames from Sami's Roblox version, already live. Learn from it, then beat it |
| `ui/` | Our own UI mockups and style references to match |
| `walls-and-art/` | Wall designs, tools, effects, map look |

Name files `NN-short-description.jpg`. If an image needs explaining, add a line about it below.

## Notes on specific images
- `original-game/01`: the punch preview grid. Orange cells take the most damage, white cells are the outer ring.
- `original-game/05`: after a Radius upgrade, the grid gets bigger (a diamond shape).
- `original-game/06-08`: the 3 upgrade tabs and every node name and price.
- `original-game/10`: a darker, rusty layer behind the front wall (the next layer).
- `roblox-competitor/01`: their HUD (Storage bar, money, 2-slot hotbar, +$1 popups).
- `roblox-competitor/04-05`: the deposit machine and the tool podium in the room.
