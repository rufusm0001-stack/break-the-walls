# Break the Walls: rules for Claude

- Roblox incremental game. This repo is shared, so `git pull` and read `STATUS.md` before doing anything.
- Follow the reference game's mechanics, but don't copy its names, art or text. Everything gets a Roblox theme.
- UI must look polished and consistent. Use one accent colour, rounded panels and readable numbers (1.2K, 3.4M, ...).
- Keep all tunable numbers (costs, wall HP, multipliers) in one Config module.
- When a session ends, log the exact Instance paths you changed in `STATUS.md`, then commit and push.
