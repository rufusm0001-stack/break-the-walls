# Break the Walls

A Roblox incremental game inspired by the Steam game *Break the Walls*. It's a reimagining with a Roblox theme and a clean, polished UI, not a 1:1 copy. Three people work on it from three devices and three accounts.

## Core loop (draft)
1. Hit the wall to earn currency.
2. Spend the currency on upgrades (damage, speed, auto-breakers).
3. Break through the wall to reach the next, tougher wall.
4. Prestige to reset for permanent multipliers.

## Repo layout
- `HANDOFF.md`: **start here.** Shows where the last agent left off.
- `CLAUDE.md`: rules every Claude session follows (start and end checklists)
- `TASKS.md`: claim a task before working on it; also lists the team and their devices
- `STATUS.md`: dated history of every session, newest first
- `DESIGN.md`: game design (walls, upgrades, prestige)
- `ui/UI_PROGRESS.md`: status of every UI screen, plus the style rules
- `ui/screenshots/`: progress screenshots of the UI
- `references/`: reference images to follow (original game, UI, art)

## Workflow
- **Start:** `git pull`, read `HANDOFF.md`, then claim a task in `TASKS.md` and push.
- **End:** rewrite `HANDOFF.md`, add an entry to `STATUS.md`, update the UI progress and add screenshots, then commit and push.
