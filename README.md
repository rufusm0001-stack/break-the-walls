# Break the Walls

A Roblox incremental game inspired by the Steam game *Break the Walls*. It's a reimagining with a Roblox theme and a clean, polished UI, not a 1:1 copy.

## Core loop (draft)
1. Hit the wall to earn currency.
2. Spend the currency on upgrades (damage, speed, auto-breakers).
3. Break through the wall to reach the next, tougher wall.
4. Prestige to reset for permanent multipliers.

## Repo layout
- `CLAUDE.md`: rules every Claude session follows in this project
- `DESIGN.md`: game design notes (walls, upgrades, prestige, UI style)
- `TASKS.md`: who owns what
- `STATUS.md`: session log, newest entry first

## Workflow
Before each session, run `git pull` and read `STATUS.md`. After each session, add a STATUS entry, then commit and push.
